# My Memo 드래그 — 구조 분석 및 변경 내용

## 원본 분석
첨부 ZIP의 MyMemo-3.5.1-test.apk와 source/ 프로젝트가 기준입니다. 참고용 MyMemo-3.4.2-release.apk도 포함돼 있습니다. 두 APK의 패키지·버전·SDK·서명을 aapt/apksigner로 확인했습니다. 수정 가능한 전체 소스가 있으므로 디컴파일이나 smali 패치 없이 소스를 재사용했습니다.

| 항목 | 확인 내용 |
|---|---|
| 개발 | Kotlin, Jetpack Compose(Material3), Android Gradle Plugin 8.13.2 |
| 목록 | Screens.kt의 ListScreen, LazyColumn, NoteRow |
| 타이틀 영역 | weight(1f) Column: 제목·미리보기·수정 시각과 여백 |
| 기존 이벤트 | 짧게 누르기=열기, 길게 누르기=다중 선택, 손잡이=드래그 |

| Android | 최소 8.0(API 26), target/compile API 36 |

## 구현
- 타이틀 정보 영역의 텍스트 또는 빈 공간을 길게 누르면 드래그가 시작됩니다. 짧게 누르면 기존 읽기 화면을 엽니다. 핸들은 제거했습니다.
- 행 전체를 목록 위의 레이어에 띄웁니다. 1.03배 확대, 은은한 배경색, 8dp 그림자, 3dp 상승, 짧은 햅틱을 적용했습니다.
- 손가락을 따라 행 전체가 이동하고 다른 행은 160ms 위치 애니메이션으로 자리를 비킵니다. 드래그 행이 원래 있던 위치가 화면 밖으로 나가도 이동이 계속됩니다.
- 위/아래 가장자리 64dp에서 자동 스크롤합니다. 정상적으로 놓을 때 Room 트랜잭션으로 순서를 저장하고 안착 효과를 해제합니다. 취소 시 저장하지 않습니다.
- 상단 ‘메모 선택’ 버튼과 각 메모 메뉴로 다중 선택·삭제를 유지합니다.
- 새 메모는 일반 메모 그룹 맨 위에 추가합니다. 고정 메모의 상단 고정과 하위 메모 계층을 유지하므로 같은 부모·같은 고정 상태 안에서 순서를 바꿉니다. 다른 부모로 옮기기는 기존 메뉴를 사용합니다.
- 검색 결과에도 사용자 지정 순서를 반영합니다. 내용 수정은 순서를 바꾸지 않습니다.
- 기존 글꼴·색상·편집·검색·템플릿·체크리스트·휴지통·잠금·4×1 다중 메모 위젯은 재사용했습니다.

## 독립 설치와 데이터 이전
새 applicationId와 새 RSA-3072 서명 키를 사용합니다. 원본의 com.personal.memostarter 및 com.personal.memostarter.preview351과 다릅니다. 소스의 Kotlin namespace와 클래스는 유지하며, 최종 매니페스트에 기록된 실제 컴포넌트·위젯 설정 클래스를 검증합니다. notes.db 이름이 같아도 데이터베이스·설정·Android Keystore는 각 앱의 저장 영역을 사용합니다.

원본에는 내보내기/가져오기 기능이 없고 allowBackup=false 및 데이터 추출 제외 규칙이 있습니다. 잠긴 메모는 기기의 앱별 암호화 키에 의존합니다. 따라서 APK만으로 기존 기기의 메모를 자동 이전할 수 없습니다. 기존 앱을 그대로 두고 메모를 열어 제목·본문을 복사해 새 앱에 붙여넣으세요. 체크리스트·계층·잠금 설정은 직접 다시 확인해야 합니다. 기존 앱을 삭제하거나 데이터를 초기화하지 마세요.

## 재빌드
JDK 17, Android SDK 36, Build Tools 35.0.0, Gradle 8.13.
테스트: `./gradlew testDebugUnitTest`
서명 빌드: `python tools/build_release.py --java-home <JDK경로> --sdk <SDK경로> --keystore <프로젝트밖의PKCS12경로> --alias release`

비밀번호는 스크립트의 숨김 프롬프트로 입력합니다. tools/release-policy.json에는 공개 인증서 SHA-256만 기록합니다. 새 키에 맞춰 기존 앱 무결성 보호도 유지했습니다. 이후 업데이트는 같은 패키지명·같은 서명 키를 쓰고 versionCode를 올려야 합니다.

## 수동 확인 권장
1. 기존 앱을 유지한 채 새 APK 설치, 두 앱 실행.
2. 짧게 누르기와 길게 누르기 구분, 타이틀 영역 각 모서리에서 시작.
3. 긴 목록에서 위/아래 끝으로 끌고 자동 스크롤, 놓은 뒤 앱 강제 종료/재실행.
4. 확대·배경색·그림자·햅틱이 기기의 글꼴/배율 설정에서도 자연스러운지 확인.
5. 고정 메모·하위 메모·검색 중 순서 변경, 메뉴·삭제·다중 선택 확인.
6. 실제 런처에 4×1 위젯 추가, 여러 메모 스크롤 및 잠금 내용 비노출 확인.
