# My Memo 3.5.1 테스트 빌드

## 변경 사항
- 메모를 길게 눌러 다중 선택, 체크박스와 선택 개수 표시, X/뒤로 가기로 선택 취소.
- 삭제 확인 후 선택 메모와 하위 메모를 한 트랜잭션으로 휴지통 이동. 기존 휴지통 항목은 보존.
- 최근 수정 탭 제거. 전체 메모, 고정 메모, 설정 탭 유지.
- 오른쪽 손잡이를 잡고 드래그하여 같은 상위 메모·같은 고정 상태 안에서 순서 변경. 화면 가장자리에서 자동 스크롤. 순서는 DB에 저장.
- 선택 중 또는 검색 중에는 드래그 비활성화. 일반 메모 영역은 스크롤/열기/길게 누르기 다중 선택에 사용.
- 기본 위젯 4×1 유지. 여러 메모 선택 및 위젯 목록 스크롤. 메모별로 눌러 열기.
- 위젯별 선택 목록과 글자 크기/가리기 설정 독립 유지. 잠긴 내용은 앱에서 잠금 해제한 상태여도 위젯에 노출하지 않음.

## 설치
APK는 `My Memo 3.5.1 테스트`라는 별도 앱입니다.
패키지: `com.personal.memostarter.preview351`, 버전 코드: 351, 최소 Android 8.0.
기존 정식 앱과 앞선 테스트 앱을 덮어쓰지 않습니다. 기존 메모가 자동 복사되지는 않습니다.
GitHub 업로드/푸시/릴리스 생성은 하지 않았습니다.

## 실기기 확인 항목
1. 메모 세 개 작성 → 하나 길게 누르기 → 다른 메모 선택 → 선택 개수/체크박스 확인.
2. 삭제 취소 시 메모 유지, 삭제 확인 시 선택 항목과 하위 메모만 휴지통 이동.
3. 휴지통에서 복원. 이전에 삭제한 하위 메모는 그대로 휴지통에 남는지 확인.
4. X 또는 뒤로 가기로 선택 해제. 메모를 짧게 누르면 열리는지 확인.
5. 최근 수정 탭이 없는지 확인.
6. 오른쪽 손잡이를 위/아래로 드래그하고 앱 재시작 후 순서 확인.
7. 일반 메모 영역을 밀면 목록이 스크롤되고 순서가 바뀌지 않는지 확인.
8. 긴 목록의 위/아래 가장자리에서 드래그 자동 스크롤 확인.
9. 고정 메모끼리, 같은 상위 메모의 하위 메모끼리 순서 변경 확인.
10. 위젯 기본 4×1 확인 → 여러 메모 선택 → 위젯 스크롤 및 각 메모 열기 확인.
11. 위젯 두 개에 서로 다른 메모를 지정하고 독립 동작 확인.
12. 위젯 메모 수정/삭제 후 갱신, 잠금·가리기 시 내용 비노출 확인.

실기기 런처에서의 위젯 표시·터치 동작은 별도 확인이 필요합니다.

## 소스 빌드
JDK 17, Android SDK 36, Build Tools 35.0.0, Gradle 8.13.
소스 폴더에서 `./gradlew assembleDebug testDebugUnitTest` 실행.
정식 릴리스 서명 및 무결성 보호는 변경하지 않았습니다.
