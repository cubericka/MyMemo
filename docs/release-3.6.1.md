정식 APK: **MyMemo-3.4.2-release.apk**. 기존 파일명을 유지했으며 실제 버전은 **3.6.1**, versionCode **361**입니다. 패키지는 `com.cubericka.mymemo.titledrag`입니다. Android 8(API 26) 이상을 지원합니다. 디버그 빌드가 아닙니다.

사용자 승인으로 새 RSA 4096비트 PKCS12 키(alias `release`)를 사용합니다. 개인 키와 비밀번호는 GitHub·Release에 포함하지 않습니다. 공개 인증서 SHA-256:

`c4e0943c2bb1aa2478f9c33ab1fe3a8926fd2d416259e36113f11004c4da7d85`

이전 서명의 동일 패키지 앱 위에 업데이트 설치할 수 없습니다. 기존 데이터를 자동 이전하지 않습니다. 기존 앱을 삭제하거나 초기화하지 마세요. `.debug` 테스트 앱과는 별도 설치됩니다. 이후 정식 업데이트는 이번 새 키로 서명하고 versionCode를 올려야 합니다.
