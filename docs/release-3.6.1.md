# MyMemo 3.6.1 (361)

첨부된 3.6.0 잉크 & 앰버 소스 기준 업데이트입니다.

- 설정 → 어플 정보: 앱 이름, 현재 버전, 제작자 `아카라이브 모르윈` 표시.
- 휴지통: 선택 삭제, 전체 비우기, 개별 영구 삭제. 삭제 전 확인하며 복원 UI는 제거했습니다. 선택한 부모의 하위 메모도 함께 삭제합니다. 사용 중인 메모나 없어진 항목이 섞이면 전체 작업을 취소합니다.
- 메인 화면의 잠금 버튼과 설정에서 앱 공통 숫자 4자리 PIN 설정·변경·사용 해제·즉시 잠금. 앱 재시작 또는 백그라운드 복귀 시 PIN 확인.
- PIN 평문을 저장하지 않습니다. PBKDF2-HMAC-SHA256(210,000회), AES-GCM과 Android Keystore로 키 봉투를 보호합니다. 실패 횟수와 재시도 제한은 재시작 후에도 유지합니다.
- 앱 PIN을 설정한 뒤 기존 개별 암호화 메모의 이전 PIN을 한 번 확인하면 이후 앱 PIN으로 엽니다. 앱 PIN을 설정하기 전에는 기존 메모 PIN 보호를 유지합니다. 메모 암호문과 기존 키 봉투를 유지합니다. 공통 PIN 변경·해제 시에도 등록한 기존 메모 키를 보존합니다.
- 앱 잠금 사용 중에는 홈 위젯 제목·내용을 숨깁니다. 위젯 설정과 외부 메모 진입에도 PIN 확인을 적용합니다.
- 공통 PIN은 앱 접근 잠금입니다. 기존 평문 메모 전체를 새로 암호화하는 기능은 아닙니다.
- 제목 영역 드래그 정렬, 다중선택, 작성·편집·검색·자동저장·4×1 다중 메모 위젯과 기존 데이터베이스 구조를 유지했습니다.

## 버전과 설치 호환성

- 패키지: `com.cubericka.mymemo.titledrag`, 버전 `3.6.1`, versionCode `361`.
- 정식 빌드의 서명 설정은 첨부된 3.6.0 계열을 유지했습니다. 기존 서명 키는 현재 작업 환경과 GitHub에 없어 동일 서명의 정식 APK는 만들지 못했습니다. 키와 비밀번호를 저장소나 CI에 올리지 않았습니다.
- GitHub 구버전 3.4.2(`com.personal.memostarter`)와는 패키지가 달라 별도로 설치됩니다. 그 앱의 데이터는 자동 이전되지 않습니다.
- APK 파일명은 요청대로 `MyMemo-3.4.2-release.apk`를 유지합니다. 실제 버전은 파일명이 아닌 앱 정보 또는 APK 메타데이터로 확인하세요.
- 기존 main 커밋 `b30e473cdcd93ea10e0610e135f5e90e26d83d88`은 `backup/legacy-version`에 보존했습니다.
- 기본 브랜치 병합은 사용자 승인 후 진행합니다.

## 제공 파일과 미완료 사항

Release는 `v3.6.1` 검토용 초안으로 준비합니다. 테스트 APK, 최신 소스 ZIP, 미서명 릴리스 입력 ZIP, 자동 검증 보고서를 포함합니다.

저장소 루트의 `MyMemo-3.4.2-release.apk`는 **기존 GitHub 3.4.2 파일**을 그대로 보존한 것입니다. 새 버전의 정식 서명본으로 오인하지 마세요. 정식 서명 키를 사용할 수 있는 환경에서 `tools/build_release.py`를 실행하면 기존 파일명을 유지한 3.6.1 APK를 만들 수 있습니다. 미서명 릴리스 입력 ZIP은 설치용 파일이 아닙니다.

기본 브랜치는 승인 전까지 병합하지 않았습니다. 동일 서명의 정식 APK 제작과 기존 앱 위 실제 업데이트 검증은 미완료입니다.
