# My Memo v3.3 — 메인 메모 중심 UI와 4자리 잠금

## 화면 변경

- 기본 빠른 메모는 제목과 넓은 본문 영역에 집중합니다.
- 아이디어·학습·의사결정·리서치·계획·정보 보관을 선택하면 해당 입력 양식을 바로 펼칩니다. 모든 항목은 선택 입력입니다.
- 체크리스트 템플릿은 체크리스트를 바로 펼칩니다. 다른 템플릿에서는 체크리스트가 기본으로 접혀 있습니다.
- 템플릿을 바꿔도 제목·본문·체크리스트·기존 상세 값은 유지합니다. 빠른 메모로 바꾼 경우 상세 항목을 펼치면 이전 값도 확인할 수 있습니다.
- 하위 메모는 화면 아래에서 요청할 때만 펼칩니다. 펼치면 각 메모가 폭 전체를 사용하는 큰 카드로 표시됩니다.
- 목록 화면도 하위 메모를 기본으로 접어 두며 화살표로 펼칠 수 있습니다.

## 메모별 비밀번호

1. 최상위 메모를 엽니다.
2. 오른쪽 위 ⋯ → ‘비밀번호 잠금 설정’을 누릅니다.
3. 숫자 4자리와 확인 값을 입력합니다.
4. 이 메모와 모든 하위 메모가 함께 보호됩니다. 이미 휴지통에 있는 해당 하위 메모도 같은 잠금을 적용합니다.
5. 메모를 닫고 목록으로 돌아가거나 앱을 백그라운드로 보내면 다시 잠깁니다. ⋯ → ‘지금 잠그기’도 가능합니다.
6. 다시 열 때 해당 상위 메모의 비밀번호를 입력합니다. 다른 최상위 메모에는 다른 비밀번호를 설정할 수 있습니다.

잠금을 완전히 제거하려면 비밀번호로 상위 메모를 연 후 ⋯ → ‘비밀번호 잠금 설정 해제’를 선택합니다.
잠긴 하위 메모를 보호 범위 밖으로 옮기려면 먼저 상위 메모의 잠금 설정을 해제해야 합니다.
잠긴 내용을 편집할 때와 비밀번호 입력 화면은 화면 캡처·최근 앱 미리보기를 제한합니다.

비밀번호를 잊으면 복구할 수 없습니다. 이번 버전에는 지문 인증, 비밀번호 재설정, 파일 백업·복원은 포함하지 않았습니다.

## 저장과 보호

내용을 수정하면 기존처럼 자동 저장합니다. 잠긴 메모는 제목·본문·체크리스트·템플릿 정보를 암호화해 저장합니다.
잠금 상태에서는 검색 결과로 보호 내용이 노출되지 않으며, 위젯은 편집 중 잠금을 푼 경우에도 보호 내용을 표시하지 않습니다.
5회 틀리면 30초 대기하며 계속 틀리면 대기 시간이 늘어납니다(최대 15분). 대기 기록은 앱을 다시 실행해도 유지합니다.
앱을 나가기 전 저장을 시도한 뒤 다시 잠급니다. 저장 실패나 갑작스러운 전원 차단 직전의 미저장 입력까지 복구를 보장하지 않습니다.

## 업데이트

이번 APK는 v3.2 검증용 APK와 같은 서명 키, versionCode 330을 사용합니다. v3.2에서는 삭제 없이 업데이트하는 경로입니다.
v3.0/v3.1과는 서명이 다릅니다. 설치 오류를 해결하려고 기존 앱을 삭제하지 마세요.
기존 메모는 DB v3→v4 이관 후 기본적으로 잠금 없는 상태를 유지합니다. 직접 잠금 설정한 메모만 암호화합니다.

## 재부팅 후 앱이 사라지는 경우

이번 소스에는 앱 삭제, 앱 데이터 초기화, 런처 아이콘 숨김을 실행하는 코드가 없습니다. 내부 저장소 설치를 명시했습니다.
그러나 이것만으로 사용 기기에서 발생한 현상의 원인을 확정하거나 해결했다고 말할 수 없습니다.

재부팅 후 다음을 확인해 주세요.

- 휴대폰 설정 → 애플리케이션 → My Memo 검색: 항목이 남아 있는지
- 홈 화면에만 없고 앱스 화면에는 있는지
- 보안 알림·앱 보관·삭제 안내가 표시됐는지
- 사용한 APK 이름과 앱 정보의 버전

앱 항목이 남아 있으면 데이터를 지우거나 앱을 삭제하지 말고 해당 화면을 전달해 주세요.

## 실기기 확인 순서

중요하지 않은 테스트 메모부터 잠금을 설정하세요. 일반 메모 생성 → 하위/체크/템플릿 입력 → 잠금 → 닫기 → 잘못된 PIN/정상 PIN 확인 → 앱 종료·재부팅 → 다시 열기 → 위젯 비공개 확인 순서입니다.
실기기 Android Keystore, 재부팅, Samsung UI, 최종 R8 APK 실행은 이 개발 환경에서 직접 검증하지 못했습니다.
