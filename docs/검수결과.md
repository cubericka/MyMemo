## 검증 범위

| 구분 | 수 | 확인한 동작 |
|---|---:|---|
| 편집/계층 규칙 | 5 | 30단계 이상 Undo, 자동 저장 뒤 Undo, 저장 요청 직렬화, 실패 재시도, 3단계·순환 방지 |
| DB/휴지통 | 6 | 삭제 구조 복원, 하위 단독 복원, 트랜잭션 롤백, 이동·고정·정렬 내용 보존, 영구 삭제 범위, v1→v3 이관·재개방 |
| 템플릿/업데이트 DB | 2 | 8종 전환 시 제목·본문·체크·상세 값 보존 및 Undo/Redo, 휴지통 복원, 기존 v2 스키마에서 v3 이관 후 계층·휴지통·순서·고정·체크 유지, 새 상세 저장 후 재개방 |
| 화면 조작 | 2 | 작성·저장·검색·다시 열기, 선택 상세 입력→템플릿 변경→기존 값 유지→상세 검색, 자동 번호 없는 제목 |
| 위젯 설정 | 1 | ID별 독립 설정, 연결 메모·글자 크기·가리기 저장, ID 복구 |

화면 조작 검사는 Compose/Robolectric API 34 환경입니다. 실제 One UI 화면이나 삼성 키보드를 검증한 결과는 아닙니다.
서명 일치 및 DB 이관 확인과, 실제 기기의 덮어쓰기 설치 성공은 구분해야 합니다.

## 미확인 및 미구현

실기기 APK 업데이트, 위젯 표시/크기 변경/재부팅, 큰 글꼴·화면 회전·한글 IME 조합 입력, 실제 붙여넣기와 앱 백그라운드 전환은 기기 검수가 남아 있습니다.
개별 메모 잠금, 파일 백업·복원, 마감일 알림, 태그 전용 필터, 웹 자료 자동 수집은 미구현입니다.
상세 항목은 일반 검색 대상으로 저장하며 위젯은 기존처럼 본문과 체크리스트를 표시합니다.
