## 설치 호환성

앞서 제공한 **새 서명 키의 정식 3.6.1(361)** 위에 업데이트 설치할 수 있도록 구성했습니다. 버전명이 3.5로 바뀌어도 Android는 더 높은 내부 버전 코드 362로 업데이트를 판단합니다. 기존 데이터 삭제나 앱 제거가 필요하지 않습니다.

그보다 이전의 다른 서명 앱에는 덮어 설치할 수 없고, `.debug` 테스트 앱의 데이터가 자동 이전되지는 않습니다. 기존 앱을 삭제하거나 초기화하지 마세요.

## 검증과 자료

[빌드·자동 테스트](https://github.com/cubericka/MyMemo/actions/runs/41735395175)에서 Android/Robolectric 60개와 배포 도구 8개가 통과했습니다. 별도 fixture가 없는 10개는 제외했습니다. 동일 키로 서명한 APK의 v2·v3 서명, 무결성, 패키지·버전·앱 이름을 확인했습니다. 게시 workflow는 Android 14 에뮬레이터에 기존 정식 3.6.1을 설치하고 메모·PIN을 설정한 뒤 3.5로 덮어 설치하여 이름·버전 변경과 데이터·잠금 유지를 검증합니다. 실제 결과는 Release의 `release-verification.json`과 `emulator-results.json`에서 확인할 수 있습니다.

실제 휴대폰, 제조사별 런처·위젯 및 다른 Android 버전의 실행은 미검증입니다. Release에는 정식 APK, 수정 가능한 소스 ZIP, 공개 인증서, 검증 보고서와 SHA-256 해시를 제공합니다. 개인 서명 키와 비밀번호는 포함하지 않습니다.

이전 v3.6.1 Release와 `backup/legacy-version`은 보존했습니다. 기본 브랜치 병합은 별도 승인 전까지 진행하지 않습니다.
