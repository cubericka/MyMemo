# Galaxy S26 Ultra 실기기 검수표

이 표는 실제 휴대폰에서 확인해야 하는 항목입니다. 아직 실기기에서 실행하지 않았으며, 자동 테스트 통과와 구분합니다.

| 항목 | 실행 방법 | 기대 결과 | 실기기 상태 |
|---|---|---|---|
| F01 | 제목 없이 여러 줄 작성 → 저장 → 앱 재실행 | 제목 없음·본문·수정일 유지 | 미확인 |
| F02 | 입력 후 1초 대기 / 바로 뒤로 / 홈 화면 전환 | 최신 내용 저장 | 미확인 |
| F03 | 제목·본문 삭제 후 Undo/Redo, 자동 저장 후 다시 Undo | 복구·재실행 및 편집 이력 유지 | 미확인 |
| F04 | 최상위 → 하위 → 하위의 하위 → 4단계 시도 | 3단계까지만 허용 | 미확인 |
| F04 이동 | 자식을 다른 부모 및 최상위로 이동, 순환 이동 시도 | 내용·ID 보존, 순환 금지, 번호 없이 제목만 표시 | 미확인 |
| F05 | 체크 항목 추가·완료·수정·삭제 후 재실행 | 내용·완료 상태 유지 | 미확인 |
| F06 두 위젯 | 서로 다른 메모 연결, 각 내용 수정 | 각각 올바른 메모 갱신 | 미확인 |
| F06 크기 | 4×1 → 4×2 확대, 글자 크기 변경 | 표시 영역·글자 크기 변경 | 미확인 |
| F06 버튼 | 본문·+·설정 터치 | 메모 열기·새 메모·설정 | 미확인 |
| F06 가리기 | 개인정보 가리기 켜기 | 제목·본문 숨김 | 미확인 |
| F06 삭제 | 연결 메모 휴지통 이동 / 위젯 삭제 | 재선택 안내 / 원본 보존 | 미확인 |
| F06 재부팅 | 위젯 두 개 설치 후 기기 재부팅 | 연결·설정·내용 유지 | 미확인 |
| F07 | 하위 본문·체크 항목에만 있는 단어 검색 | 경로와 검색 결과, 직접 열기 | 미확인 |
| F08 | 여러 메모 고정·순서 변경·재실행 | 그룹별 순서 유지 | 미확인 |
| F09 | 부모 구조 삭제→복원 / 자식만 복원 / 영구 삭제 취소 | 구조 복원 / 위치 선택 / 취소 시 보존 | 미확인 |
| F10 | 웹페이지의 서식 있는 여러 줄 텍스트 붙여넣기 | 문자·줄바꿈 유지, 외부 서식 제거 | 미확인 |
| 오프라인 | 비행기 모드에서 주요 기능 사용 | 정상 사용 | 미확인 |
| 한국어 입력 | 삼성 키보드 조합·선택·붙여넣기 | 입력·커서·저장 정상 | 미확인 |
| 화면 회전 | 편집 중 회전 후 Undo | 내용·이력 유지 | 미확인 |
| 앱 업데이트 | 같은 키·높은 versionCode로 덮어 설치 | 메모·체크·휴지통·위젯 설정 보존 | 미확인 |

문제 전달: 휴대폰 모델 / Android·One UI 버전 / 앱 버전 / 수행 순서 / 기대 결과 / 실제 결과 / 가능하면 화면 캡처.
실기기 확인 전 중요한 기록의 유일한 저장소로 쓰지 마세요. 앱 삭제·데이터 초기화로 설치 문제를 해결하지 마세요.

## v3.1 추가 확인 (실기기 미확인)

- 기존 v3.0 APK에서 삭제 없이 업데이트하고 원래 메모·체크·휴지통·위젯 연결 확인
- 8종 템플릿 선택, 상세 항목 입력, 템플릿 변경 후 기존 값 유지 확인
- 수정일 한 줄과 저장 상태, 체크리스트/하위 메모 터치 영역 확인
- 큰 글꼴·키보드·화면 회전에서 입력 및 스크롤 확인
