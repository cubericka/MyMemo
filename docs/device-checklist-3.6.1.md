# MyMemo 3.6.1 실기기 확인표 — 아직 실행하지 않음

자동 테스트와 별도로 실제 Android 기기에서 확인할 항목입니다. 이 표의 항목은 성공으로 기록하지 않았습니다.

## 설치 및 데이터

- 테스트 APK: 앱 이름 `My Memo 드래그 테스트`, 패키지 `com.cubericka.mymemo.titledrag.debug`, 버전 3.6.1(361).
- 테스트 APK 설치 후 기존 앱이 별도로 남아 있고 원래 메모가 그대로인지 확인합니다. 테스트 앱에 기존 메모가 자동으로 나타나지는 않습니다.
- 정식 업데이트는 기존 3.6.0 서명 키로 `tools/build_release.py`를 실행해 만든 APK에서 확인해야 합니다. 테스트 APK를 기존 앱의 업데이트 파일로 사용하지 않습니다.
- 정식 서명 후 3.6.0에 업데이트 설치하여 메모 ID, 본문, 체크리스트, 순서, 설정, 기존 암호화 메모를 확인합니다. 기존 앱 삭제나 데이터 초기화 없이 시험합니다.

## 앱 공통 PIN

- 메모 편집 옵션에 `앱 잠금 설정`이 없고, 메모 정보·상단 고정·이동·휴지통 기능은 남아 있는지 확인합니다.
- 메인 잠금 버튼과 설정에서 숫자 4자리 PIN을 설정하고, 두 번 입력한 값이 다르면 설정되지 않는지 확인합니다.
- 지금 잠그기, 홈 화면 이동 후 복귀, 앱 완전 종료 후 재실행에서 PIN이 요구되는지 확인합니다.
- 자동 저장 중 홈으로 이동하고 위젯이나 외부 메모 링크로 돌아올 때 제목·내용이 잠깐 노출되지 않는지 확인합니다.
- 틀린 PIN은 접근을 막고 5회 실패 후 재시도 대기 시간이 적용되는지, 재시작 후에도 제한이 유지되는지 확인합니다.
- 현재 PIN 확인 후 새 PIN으로 변경하고, 이전 PIN이 거부되는지 확인합니다.
- 현재 PIN으로 사용 해제 후 재실행하여 PIN 없이 열리는지 확인합니다.
- 앱 PIN 사용 중 기존 개별 잠금 메모의 이전 PIN을 한 번 확인한 뒤, 앱 재시작·PIN 변경 후에도 내용을 열 수 있는지 확인합니다.
- 앱 PIN 설정 전에는 기존 개별 잠금 메모를 한 번 열어도 다음 세션에서 이전 PIN이 계속 요구되는지 확인합니다.

## 휴지통 및 기존 기능

- 여러 항목 선택 삭제, 전체 비우기, 개별 영구 삭제에서 확인 창이 나타나고 취소 시 데이터가 남는지 확인합니다.
- 선택하지 않은 메모는 남고, 선택한 부모 메모의 하위 메모만 함께 삭제되는지 확인합니다.
- 휴지통에 복원 버튼이 없는지 확인합니다.
- 작성, 자동·수동 저장, 읽기·수정, 검색, 체크리스트, 고정, 폴더 이동, 다중선택을 확인합니다.
- 제목 텍스트·여백 길게 누르기, 위·아래 드래그, 자동 스크롤, 드롭 후 효과 해제, 재시작 후 순서 유지를 확인합니다.
- 4×1 위젯과 여러 메모 표시를 확인합니다. 앱 PIN 사용 중 위젯의 이전 캐시까지 가려지고, 위젯 진입 시 PIN을 요구하는지 확인합니다.
- 설정 → 어플 정보에서 이름, 3.6.1(361), `제작자: 아카라이브 모르윈`을 확인합니다.

## 기기별 확인

Android 8 이상 기기의 실제 Android Keystore, 기기 회전, 멀티윈도, 제조사별 런처, 최근 앱 화면 가리기, 접근성 및 큰 글꼴 설정을 확인합니다. Robolectric 결과는 실기기 검사나 설치 성공을 대신하지 않습니다.
