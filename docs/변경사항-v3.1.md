# My Memo 3.1.0-preview

2026-10-13 요청 반영. 앱 내부 데이터는 오프라인에만 저장합니다.

- 목록의 A·B 및 하위 자동 번호 제거. 사용자가 제목에 직접 입력한 문자는 그대로 유지합니다.
- 체크리스트와 하위 메모를 별도 구역으로 구분하고 각각 접기/펼치기를 제공합니다. 추가 버튼도 각 구역에 배치했습니다.
- 체크리스트는 완료 개수를 머리글에 통합했습니다. 하위 메모는 테두리 카드로 표시합니다.
- 저장 상태는 상단 작은 글씨, 수정일은 템플릿 옆 한 줄로 정리했습니다. 작성일은 편집 메뉴 → 메모 정보로 이동했습니다.
- 하단의 혼잡한 아이콘들을 템플릿 변경·저장으로 정리했습니다. 상단 고정은 편집 메뉴에서 선택합니다.
- 빠른 메모, 아이디어, 체크리스트, 학습 노트, 의사결정, 자료 수집 / 리서치, 목표 / 계획, 정보 보관 등 8종 템플릿을 추가했습니다.
- 모든 템플릿에서 제목·본문 자유 입력 가능. 필수 입력 항목은 없습니다.
- 상세 항목은 접힌 상태가 기본입니다. 필요할 때 펼쳐 선택 입력합니다.
- 템플릿을 바꿔도 제목·본문·체크 항목·이전 상세 값을 삭제하지 않습니다. 이전 항목도 상세 영역에서 계속 편집할 수 있습니다.
- 템플릿 선택과 상세 항목 변경은 자동 저장 및 Undo/Redo에 포함합니다. 상세 값은 일반 검색 대상입니다.
- 마감일·태그·URL은 일반 텍스트 정보입니다. 날짜 알림·달력 연동·태그 전용 필터·웹 가져오기는 이번 범위에 포함하지 않습니다.

## 업데이트

기존 전달한 MyMemo-v3-preview.apk와 앱 ID 및 서명 키가 같습니다. 버전 코드는 300 → 310입니다.
기존 앱을 삭제하지 않고 새 APK로 업데이트하세요. DB v2 → v3는 템플릿 관련 열만 추가합니다.
이전에 별도 키로 직접 빌드한 앱이면 같은 서명 키로 다시 빌드해야 합니다. 설치 오류를 앱 삭제로 해결하지 마세요.

## 남은 확인

Galaxy S26 Ultra에서 실제 설치·업데이트·큰 글꼴·키보드·위젯·재부팅은 사용 기기에서 확인해야 합니다.
선택 기능인 개별 메모 잠금과 파일 백업·복원은 아직 포함하지 않았습니다.
