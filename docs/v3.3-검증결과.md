## 암호화 설계와 남은 위험

각 최상위 메모에 무작위 256비트 데이터 키를 생성합니다. 내용은 AES-256-GCM, 메모/상위 ID에 결합된 AAD로 암호화합니다. PIN은 임의 salt와 PBKDF2-HMAC-SHA256 210,000회로 키를 유도해 데이터 키를 감싸고, 그 결과를 기기 AndroidKeyStore AES-GCM 키로 다시 감쌉니다. PIN 평문은 DB에 저장하지 않습니다. Keystore 키는 생체인증을 요구하도록 설정된 키가 아닙니다.

5회 실패 후 30초 대기, 이후 최대 15분까지 증가합니다. 실패 상태는 DB에 저장합니다. 4자리 PIN은 가능한 조합이 적으며 로컬 제한은 루팅·런타임 변조·후킹에 완전하지 않습니다. R8와 무결성 검사 자체도 패치 가능하므로 역공학/변조의 완전 방지를 주장하지 않습니다.

제목·본문·체크리스트·템플릿 내용은 보호하지만 ID·계층·시각·정렬·잠금 여부 등 메타데이터는 평문입니다. secure_delete/저널 설정은 이전 평문이 플래시나 백업에서 완전히 지워졌음을 보장하지 않습니다. 백그라운드 저장 실패 시 미저장 초안은 메모리에 남으며 프로세스 종료 시 손실될 수 있습니다.

지문, PIN 복구, 파일 백업·복원은 미구현입니다. 실제 기기 키 손실·앱 삭제 시 보호 데이터를 복구할 수 없습니다. 중요한 메모 전에 테스트 메모로 검수하세요.

v3.2→v3.3은 동일 패키지/서명 및 버전 증가이고 DB 이관을 테스트했지만 실제 업데이트 설치는 미검증입니다. v3.0/v3.1은 서명이 달라 바로 업데이트할 수 없습니다. 설치 오류 때문에 기존 앱을 삭제하지 마세요.

재부팅 후 앱이 사라졌다는 보고의 원인은 미확인입니다. 소스에서 앱 삭제/데이터 초기화/아이콘 숨김 동작은 발견하지 못했습니다. 설정→애플리케이션의 설치 상태와 사용 APK 버전을 확인해야 합니다.
